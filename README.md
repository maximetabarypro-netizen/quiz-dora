# Landing quiz · Decathlon × Dora (prototype étudiant)

Projet ECV Nantes, collaboration fictive. Le formulaire n'envoie aucune donnée.

## Mise en ligne avec GitHub Pages

1. Sur github.com, créer un dépôt public, par exemple `quiz-dora`.
2. « Add file » → « Upload files » : glisser `index.html` et les dossiers `assets` et `fonts`, puis « Commit changes ».
3. « Settings » → « Pages » → Source : « Deploy from a branch », branche `main`, dossier `/ (root)` → « Save ».
4. Après 1 à 2 minutes, la page est en ligne à l'adresse `https://<nom-utilisateur>.github.io/quiz-dora/`.
